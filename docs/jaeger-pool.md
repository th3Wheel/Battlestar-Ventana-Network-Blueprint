## 🛡️ Pacific Rim Jaeger Pool

Canonical hostname pool for personal computers and laptops.

- _Assigned devices_ are italicized
- Retired names are ~~struck out~~
- Status column shows availability
- Pool column shows whether a name is canonical or alternate (see `docs/naming-conventions.md`)
- Names may be recycled **only if the system is a direct replacement**
