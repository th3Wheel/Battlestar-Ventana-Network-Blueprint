# Jinja2 Template Linting with DJLint

This directory contains Jinja2 templates used throughout the Home Assistant configuration. These templates are linted using [DJLint](https://djlint.com/), a modern linter for Jinja2/Django templates.

## What is DJLint?

DJLint is a template linter that:

- Validates Jinja2 syntax and structure
- Enforces consistent formatting
- Detects common template errors
- Supports auto-formatting

## Configuration

The configuration is in the root `.djlintrc` file:

```json
{
  "profile": "jinja",
  "extension": "yaml,jinja,jinja2,j2",
  "indent": 2,
  "max_line_length": 180,
  "ignore": "H006,H021,H025,H030,H031,J018"
}
```

## VS Code Tasks

### Lint Templates

```
Run Task > Lint: Jinja2 Templates
```

Checks templates for syntax errors and style issues.

### Format Templates

```
Run Task > Format: Jinja2 Templates
```

Auto-formats templates to match style guidelines.

### Lint All (includes templates)

```
Run Task > Lint: All
```

Runs all linters including Jinja2 template validation.

## Manual Usage

```powershell
# Lint all templates
djlint --lint ha/templates/*.yaml

# Format all templates
djlint --reformat ha/templates/*.yaml

# Check specific file
djlint --lint ha/templates/energy-cost.template.yaml
```

## Why Not YAMLlint?

YAMLlint treats Jinja2 syntax (`{{ }}`, `{% %}`, `{# #}`) as invalid YAML. To avoid false positives:

1. **Template files are excluded from yamllint** via `.yamllint`:

   ```yaml
   ignore: |
     ha/templates/*.template.yaml
   ```

2. **DJLint validates templates separately** with Jinja2 awareness

This hybrid approach ensures:

- Pure YAML files are validated by yamllint
- Jinja2 templates are validated by DJLint
- No false positives from Jinja2 syntax

## Ignored Rules

- **H006**: Img tag should have alt attribute (not applicable to YAML)
- **H021**: Inline styles (not applicable to YAML)
- **H025**: Tags should be closed (YAML has different syntax)
- **H030**: Meta tags (not applicable to YAML)
- **H031**: Meta description (not applicable to YAML)
- **J018**: Internal links should not be empty (YAML structure differs)
